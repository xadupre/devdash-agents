CI status
=========

Live GitHub Actions results are loaded when you open this page. Reload to refresh.
The latest run on the repository's default branch indicates each workflow's
current status; follow its link to inspect individual jobs.

The rolling 24-hour failure ratio covers runs **created** during that period,
across all branches and events. It counts ``failure``, ``timed_out`` and
``startup_failure`` as failures, divided by successes plus failures.
Pending, cancelled, skipped, neutral and approval-required runs are excluded.
An empty sample is shown as unavailable, not as a zero failure rate.
